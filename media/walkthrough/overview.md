# Find your way around

* **Overview** (**VM: Open Overview**): machines by state, processors and memory allocated against
  what the nodes have, a card per node, and one table of every machine across all clusters with a CPU
  sparkline. Select several rows to start or shut them down together.
* **Favorites and groups**: the **Groups** view holds **Favorites** and groups of your own; drag
  machines in from the Clusters view. **VM: Group By…** groups the main view by cluster, group or
  state.
* **Search Virtual Machines…** jumps to a machine by name.
* **Show Log** shows what happened to a machine: your actions, state changes made elsewhere, guest
  commands and snapshots, with the hypervisor's own log underneath where it has one.
* **Notifications** tell you when a machine starts or stops without you asking for it here.
* The **status bar** shows how many machines are running; click it to open the Overview.
