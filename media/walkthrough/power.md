# Managing virtual machines

Use the actions next to a virtual machine in the **Virtual Machines** view, its context menu, the
Command Palette (`VM: …`) or the Overview.

| Action | What it does |
|---|---|
| **Start** | Powers the machine on (or resumes it). |
| **Shut Down** | Asks the guest operating system to shut down cleanly (ACPI / integration services). |
| **Reboot** | Restarts the machine. |
| **Stop (Power Off)** | Cuts the power immediately. Unsaved data in the guest may be lost. |
| **Settings** | Opens the settings editor for processors, memory, media, network and more. |
| **Delete** | Removes the machine, optionally including its disks. |
